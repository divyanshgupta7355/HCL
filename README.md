🌍 Air Quality Index (AQI) Analysis of Indian Cities (2016–2025)

📌 Project Overview

This project analyzes the Air Quality Index (AQI) of Indian cities over a 10-year period, from 2016 to 2025. It uses Python, Pandas, and data visualization techniques to explore pollution levels, compare cities, and identify long-term air quality trends.

🎯 Objectives

- Analyze AQI trends across Indian cities.
- Identify the five most polluted cities.
- Identify the five cleanest cities.
- Compare annual AQI values across states and union territories.
- Calculate average AQI and percentage changes over time.
- Visualize state-wise air quality using a heatmap.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

📊 Key Features

- Dataset overview and statistical summary.
- Year-wise missing-value analysis.
- Top 5 most polluted cities.
- Top 5 cleanest cities.
- AQI improvement and decline analysis.
- State-wise annual AQI heatmap (2016–2025).

📁 Project Files

- "hcl_aqi_project.py" — Main Python analysis script.
- "indian_cities_raw_aqi_dataset_133cities_2016_2025.csv" — AQI dataset.
- ".vscode/settings.json" — VS Code project settings.

🚀 How to Run

1. Install Python.

2. Install the required libraries:
   
   pip install pandas numpy matplotlib seaborn

3. Clone this repository:
   
   git clone https://github.com/divyangshgupta7355/HCL.git

4. Open the project folder.

5. Run the Python script:
   
   python hcl_aqi_project.py

Make sure the CSV dataset is in the same folder as the Python script.

📈 Visualization

The project generates a state-wise annual AQI heatmap for 2016–2025, helping users compare air quality patterns across different regions.

🎓 Project Purpose

This project demonstrates data analysis, statistical computation, and visualization using Python, with a focus on air pollution trends in India.
